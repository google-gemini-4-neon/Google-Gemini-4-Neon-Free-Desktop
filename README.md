## Running Neon in AI Studio or Antigravity
1. Unpack the desktop workspace and open the model picker (`gemini-4-neon`).
2. Choose `low`, `medium`, `high`, or `xhigh` thinking depth (`neon/model_card.json`).
3. Feed PDFs, spreadsheets, audio, video, or multi-file repositories into the 1M context window.
